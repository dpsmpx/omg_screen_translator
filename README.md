# Экранный переводчик для игр (omg_screen_translator)

[![Build APK](https://github.com/dpsmpx/omg_screen_translator/actions/workflows/build.yml/badge.svg)](https://github.com/dpsmpx/omg_screen_translator/actions/workflows/build.yml)

Android-приложение, которое переводит текст прямо поверх запущенной игры.
Нажимаете «Перевод» на плавающей панели — приложение делает снимок экрана,
распознаёт текст и рисует перевод на месте оригинала.

Распознавание и перевод работают **на телефоне, без отправки снимков в интернет**
(Google ML Kit). Интернет нужен только один раз — чтобы скачать языковые модели.

## Возможности

- **Языки игры:** японский, китайский, английский, испанский.
- **Перевод на:** русский, английский, испанский.
- Плавающая панель поверх игры: `≡` (перетащить) · `Перевод` · `JA→RU` (сменить язык игры) · `Скрыть`.
- Перевод показывается на месте исходного текста; размер шрифта подбирается автоматически.
- Касания проходят сквозь перевод к игре (в том числе на Android 12+).
- Учитывается поворот экрана.
- **Режим root** (по желанию): снимок экрана через `su screencap`, без системного запроса на запись экрана.

## Требования

- Android 11 или новее.
- Телефон на процессоре ARM (`arm64-v8a` или `armeabi-v7a`) — это практически все телефоны.
- Около 150 МБ свободного места под языковые модели.

## Где взять APK

APK собирается автоматически через GitHub Actions при каждом изменении в репозитории.

1. **Releases** (проще всего): справа на главной странице репозитория откройте
   раздел **Releases**, выберите последнюю сборку `Build N` и скачайте файл
   `GameScreenTranslator-1.0.N.apk`.
2. **Actions:** вкладка **Actions** → последний зелёный запуск **Build APK** →
   внизу страницы артефакт `GameScreenTranslator-apk` (нужно войти в GitHub;
   внутри zip-архива лежит APK).

Все сборки подписаны одним и тем же ключом, поэтому новую версию можно ставить
поверх старой — удалять приложение не нужно.

## Установка и первый запуск

1. Скачайте APK на телефон и откройте его. Если Android спросит — разрешите
   установку из этого источника (браузера или файлового менеджера).
2. Откройте «Экранный переводчик» и выберите **язык игры** и **язык перевода**.
3. Нажмите **«1. Разрешить показ поверх других окон»** и включите разрешение
   для приложения.
4. Нажмите **«2. Скачать языковые модели»** (лучше по Wi-Fi). Внизу экрана
   видно, какие модели уже скачаны.
5. Нажмите **«3. Запустить переводчик»** и в системном окне выберите
   **«Начать»** / **«Весь экран»**.
6. Откройте игру. Когда на экране появится текст, нажмите **«Перевод»**
   на плавающей панели. **«Скрыть»** убирает перевод.

Остановить переводчик можно кнопкой в приложении или кнопкой «Остановить»
в уведомлении.

### Режим root

Если на телефоне есть root (Magisk и т. п.), можно включить галочку
«Режим root». Тогда снимок экрана делается через `su`, и система не
спрашивает разрешение на запись экрана при каждом запуске. При включении
появится запрос root-доступа — его нужно разрешить.

## Сборка самостоятельно

Нужны JDK 17 и Android SDK (платформа 35).

```bash
./gradlew assembleDebug        # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # unit-тесты
```

Путь к Android SDK задаётся переменной `ANDROID_HOME` или файлом
`local.properties` (`sdk.dir=/путь/к/sdk`).

## Как устроена сборка в GitHub Actions

Файл `.github/workflows/build.yml` запускается при каждом push, при pull request
и вручную (кнопка **Run workflow** на вкладке Actions):

1. ставит JDK 17 (с кэшем Gradle);
2. запускает unit-тесты и собирает `assembleDebug` через Gradle Wrapper;
3. выкладывает APK как артефакт запуска;
4. для push и ручного запуска создаёт релиз `build-N` с APK, привязанный к собранному коммиту.

## Структура проекта

```
app/src/main/java/com/example/gametranslator/
├── MainActivity.kt        главный экран: языки, разрешения, модели, запуск/остановка
├── TranslatorService.kt   служба: плавающая панель, снимок экрана, распознавание, перевод
├── OverlayResultView.kt   прозрачный слой, рисующий перевод поверх игры
├── FramePacker.kt         упаковка кадра записи экрана в Bitmap
└── Langs.kt               список языков и сохранённые настройки
app/src/test/...           unit-тесты
app/debug.keystore         постоянный отладочный ключ подписи
```

## Примечания

- `app/debug.keystore` — обычный **отладочный** ключ (пароль `android`). Он нужен
  только для того, чтобы обновления ставились поверх старой версии. Для публикации
  в Google Play используйте собственный ключ.
- Качество перевода зависит от ML Kit: это офлайн-перевод, он проще онлайн-сервисов.
- Стилизованные «игровые» шрифты и текст поверх пёстрого фона распознаются хуже.
